# مراجع قرارداد FSE — `igbz-store-theme` (فاز ۶۰)

این پوشه **اسکلت مرجع** خروجی نوع ۱ پادو است (ADR-0003): قالب فرزند بلوکی روی
قالب هستهٔ مصوب، **فاقد PHP، فاقد جاوااسکریپت تولیدی، فاقد فراخوانی شبکه و
وابستگی CDN**. همین پوشه فیxture طلایی تست‌هاست: هرچه اینجا می‌گذاریم، همان
«مقبول» تعریف می‌شود؛ اعتبارسنج سخت‌گیر (`ThemeContract`) همین را در بک‌اند
پاس می‌کند.

## ساختار اجباری (قرارداد پذیرش)

| مسیر | نقش |
|---|---|
| `style.css` | هدر قالب با `Theme Name` و `Template: twentytwentyfive` (قالب مادر بلوکی مصوب) |
| `theme.json` | توکن‌های طراحی نسخهٔ ۳ (`$schema` رسمی wp.org؛ بدون هیچ فونت/تصویر خارجی) |
| `templates/index.html` | قالب پشتیبان — «فایل تعیین‌کنندهٔ» قالب بلوکی در هستهٔ وردپرس |
| `templates/page.html` · `templates/single.html` · `templates/404.html` | سلسله‌مراتب استاندارد |
| `templates/archive-product.html` · `templates/single-product.html` | قرارداد ووکامرس (ADR-0003: قالب‌های ووکامرس جزو پذیرش‌اند) — بازنویسی حداقلیِ همیشه‌معتبر با بلوک‌های هسته؛ غنی‌سازی با بلوک‌های ووکامرس مجاز است |
| `parts/header.html` · `parts/footer.html` | بخش‌های سربرگ/پابرگ ثبت‌شده در `theme.json.templateParts` |
| `rtl.css` | قرارداد راست‌چین (به‌علاوهٔ ویژگی‌های منطقی CSS در همه‌جا) |

## قواعدی که اعتبارسنج سخت‌گیر پاس می‌کند (`ThemeContract::validate_php_free`)

1. **صفر فایل PHP و صفر فایل JS** در کل درخت — حتی `functions.php`؛ خروجی نوع ۱
   هرگز کد اجرایی نمی‌برد.
2. `style.css` باید هدر `Template:` با قالب مادرِ لیست‌مجاز داشته باشد.
3. `templates/index.html` و همهٔ قالب‌ها/بخش‌های اجباری بالا باید موجود باشند.
4. `theme.json` باید JSON معتبر با `version` مجاز باشد.
5. **هیچ نشانی شبکه‌ای** (`https?://…`) در CSS/JSON/HTML — تنها استثنا کلید
   `$schema` در `theme.json` که شناسهٔ اسکیماست، نه درخواست شبکه.
6. همهٔ قواعد عمومی `ThemeValidator` (سقف حجم/تعداد، پسوندها، الگوهای ممنوع،
   مسیرها) همچنان برقرارند.

## منابع بیرونی مبنای قرارداد

- مستندات توسعه‌دهندهٔ وردپرس — Block Themes: حداقلِ قالب بلوکی =
  `style.css` + `templates/index.html`؛ `index.php` برای WP ≥ 5.9 لازم نیست و
  فرزندِ قالب بلوکی خودش بلوکی شمرده می‌شود.
- مستندات theme.json — نسخهٔ اسکیمای ۳ (نسخهٔ جاری ۲۰۲۶).
- ADR/ADR-0003-THREE-THEME-OUTPUTS.md — سه خروجی، قواعد نوع ۱.

## برای توسعه‌دهنده/پادو

- غنی‌سازی قالب‌های ووکامرس مجاز است، فقط با نشانه‌گذاری بلوکی معتبر و بدون
   PHP/JS/شبکه؛ اعتبارسنج همان‌جا جلوی انحراف را می‌گیرد.
- فونت وزیرمتن از پشتهٔ سیستم می‌آید (`local`/fallback). افزودن وزیرمتن محلی
  (woff2 داخل بسته) مجاز است؛ بارگیری از CDN هرگز.
