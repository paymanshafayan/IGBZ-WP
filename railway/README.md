# پیش‌نمایش دائمی فروشگاه روی ریل‌وی — راهنمای گام‌به‌گام

> ثبت: ۱۴۰۶/۰۶/۰۳ · هدف: یک آدرس ثابت و همیشه‌روشن برای دیدن فروشگاه با آخرین کد مخزن
> (جایگزین پیش‌نمایش موقتی سندباکس که با پیام «سندباکس پیدا نشد» می‌مرد)

## اجزای این پوشه

| فایل | نقش |
|---|---|
| `Dockerfile` | ایمیج وردپرس رسمی + ابزار خط فرمان + کپی افزونهٔ igbz-suite از مخزن |
| `entrypoint.sh` | بوت‌استرپ خودکار: نصب هسته، ووکامرس، igbz-suite، زبان فارسی — بدون ویزارد |
| `mu-plugins/` | همان mu-plugin های آزمودهٔ محیط توسعه (ماژول‌ها، سلامت، بوت‌استرپ ۰۳۰، بذر ۱۰۰) |
| `../railway.json` | تنظیم بیلد ریل‌وی (مسیر داکرفایل) |
| `../_devenv/github-workflow-railway-volume.yml` | نسخهٔ مرجع ورک‌فلوی «نگهبان ولوم» |

## گام‌های راه‌اندازی (پنل ریل‌وی — یک‌بار)

۱. **پروژهٔ جدید** بسازید (یا پروژهٔ موجودتان را باز کنید).

۲. **دیتابیس:** دکمهٔ + ← ‏Database ← **MySQL** (قاعدهٔ پروژه: همیشه مای‌اس‌کیوال).

۳. **سرویس فروشگاه:** دکمهٔ + ← ‏GitHub Repo ← مخزن `IGBZ-WP` را انتخاب کنید.
   نام سرویس را همان **IGBZ-WP** (نام مخزن) بگذارید — ورک‌فلوی ولوم به همین نام تکیه دارد.
   ریل‌وی `railway.json` را می‌خواند و از `railway/Dockerfile` بیلد می‌گیرد.

۴. **متغیرهای محیطی** سرویس فروشگاه (تب Variables):

```
WORDPRESS_DB_HOST=${{MySQL.MYSQLHOST}}:${{MySQL.MYSQLPORT}}
WORDPRESS_DB_NAME=${{MySQL.MYSQLDATABASE}}
WORDPRESS_DB_USER=${{MySQL.MYSQLUSER}}
WORDPRESS_DB_PASSWORD=${{MySQL.MYSQLPASSWORD}}
WP_ADMIN_USER=admin
WP_ADMIN_PASSWORD=<یک رمز قوی بگذارید>
WP_ADMIN_EMAIL=<ایمیل شما>
```

۵. **دامنهٔ عمومی:** تب Settings ← ‏Networking ← ‏Generate Domain.
   (متغیر `RAILWAY_PUBLIC_DOMAIN` خودکار در دسترس اسکریپت است؛ آدرس سایت خودش تنظیم می‌شود.)

۶. **ولوم دائمی:** دو راه —
   - خودکار (توصیه‌شده): ورک‌فلوی «نگهبان ولوم» را نصب کنید (بند بعد) تا خودش بسازد؛
   - دستی: روی سرویس ← ‏Attach Volume ← مسیر `/var/www/html/wp-content`.

## ورک‌فلوی «نگهبان ولوم» (سیکرت `RAILWAY_TOKEN` ساخته شده ✅)

محتوای `_devenv/github-workflow-railway-volume.yml` را در مسیر
`.github/workflows/railway-volume.yml` بسازید (مثل دو ورک‌فلوی قبلی — از رابط گیت‌هاب).
رفتار: اول فهرست ولوم‌ها را چک می‌کند؛ **اگر ولومی روی مسیر محتوا نبود، خودش می‌سازد**؛
اگر بود، دست نمی‌زند. اجرا: خودکار با هر تغییر پوشهٔ `railway/` روی شاخهٔ اصلی، یا دستی
از تب Actions ← ‏Run workflow.

⚠️ توکن باید «Project Token» باشد (ساخته‌شده داخل همان پروژهٔ ریل‌وی که سرویس آنجاست)،
وگرنه CLI پروژه را پیدا نمی‌کند.

## پس از اولین استقرار

- چند دقیقه صبر کنید (بیلد + بوت‌استرپ). لاگ سرویس باید در پایان بنویسد: `igbz: bootstrap done`.
- آدرس عمومی را باز کنید: فروشگاه فارسی راست‌چین با ۲۵ محصول نمونه بالا می‌آید.
- پیشخوان: `/wp-admin` با نام کاربری و رمزی که در متغیرها گذاشتید.
- بررسی سلامت: `‎/?igbz_health=1` باید ۷۲ جدول و هر ۶ ماژول را نشان بدهد.

## نکته‌ها

- هر ادغام روی شاخهٔ اصلی ← استقرار خودکار نسخهٔ جدید؛ داده‌ها (دیتابیس + ولوم) می‌مانند.
- بذر نمونه و بوت‌استرپ فقط بار اول اجرا می‌شوند (محافظ داخلی mu-plugin ها).
- این محیط «پیش‌نمایش» است؛ سخت‌سازی تولید (پشتیبان‌گیری، دامنهٔ اصلی و…) بحث جداست.
