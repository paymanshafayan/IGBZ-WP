# بکاپ ویرا — نقطهٔ بازگشت سالم

## این بکاپ چیست

عکس کامل پوشهٔ `vira/` به‌علاوهٔ دو راه‌انداز ریشه، در وضعیتی که **آزموده و سالم**
است. اگر Codex (یا هر تغییر دیگری) چیزی را خراب کرد، با یک دستور به همین نقطه
برمی‌گردی.

| | |
|---|---|
| **نسخه** | ۰.۹.۹ |
| **کامیت** | `647b5b1` |
| **تاریخ** | ۱۴۰۵/۰۵/۳۰ |
| **وضعیت تست** | ۳۷۷ موفق، ۱ ناموفق (فقط تست داکر که محیطی است) |
| **حجم** | ۷۱۱ کیلوبایت |

## چه چیزی داخلش هست

کل `vira/` (۱۲۶ فایل: `src/`, `ui/`, `test/`, اسناد طراحی، `package.json`،
`package-lock.json`) به‌علاوهٔ `vira.sh` و `vira.cmd` از ریشهٔ مخزن.

`node_modules/` عمداً داخلش **نیست** — با `npm ci` از روی `package-lock.json`
بازسازی می‌شود و گذاشتنش حجم را ۳۰ مگابایت می‌کرد.

## بازگرداندن

```bash
cd /home/user/IGBZ-WP
./_backup/restore.sh
```

اسکریپت قبل از هر کاری از وضعیت فعلی یک عکس اضطراری می‌گیرد، پس حتی اگر اشتباهی
بازگرداندی، کار فعلی‌ات از دست نمی‌رود.

### دستی، اگر اسکریپت را نخواستی

```bash
cd /home/user/IGBZ-WP
rm -rf vira
tar -xzf _backup/vira-0.9.9-647b5b1-*.tar.gz
cd vira && npm ci
```

### فقط یک فایل را برگردان

```bash
tar -xzf _backup/vira-*.tar.gz -C /tmp vira/src/net.js
cp /tmp/vira/src/net.js vira/src/net.js
```

## راه دوم: از خود گیت

این بکاپ **جایگزین گیت نیست، مکمل آن است.** هر چیزی که کامیت شده روی
GitHub هم هست:

```bash
git checkout 647b5b1 -- vira/          # فقط پوشهٔ ویرا
git reset --hard 647b5b1                 # کل مخزن (مواظب باش)
```

بکاپ فایلی وقتی به درد می‌خورد که درخت کاری آشفته شده، یا تغییرات کامیت‌نشده‌ای
هست که نمی‌خواهی گم شوند، یا اصلاً به گیت دسترسی نداری.

## بعد از بازگرداندن، این را چک کن

```bash
cd vira
node src/cli.js --version     # باید 0.9.9 بدهد
node test/run.mjs             # باید ۳۷۷ موفق، ۱ ناموفق بدهد
```

اگر عدد تست‌ها فرق داشت، بازگرداندن ناقص بوده.

## نکته

آرشیو در `.gitignore` است و به گیت نمی‌رود — یک فایل باینری ۷۱۱ کیلوبایتی در
تاریخچه جایی ندارد، آن هم وقتی محتوایش عیناً همان کامیت `647b5b1` است. یعنی
**این فایل روی همین ماشین است و با کلون تازه نمی‌آید.** اگر ماشین عوض شد، از
`git checkout 647b5b1` استفاده کن.
