# گزارش تست ویژوال — فاز ۶۱ (artefact امضاشده، پیش‌نمایش، rollback واقعی)

تاریخ: ۱۴۰۶/۰۶/۰۹ (۲۹ اوت ۲۰۲۶) · ابزار: Chromium واقعی (Playwright 1.62.1 + @sparticuz/chromium 149)

## سطح بازبینی‌شده

یک ویترین، دو حالت — مقایسهٔ بصریِ «زنده در برابر فرزندِ امضاشده»: اسکرین‌شات
تمام‌صفحهٔ ویترین با قالب پایه (twentytwentyfive) و با قالب فرزندِ عبورکرده از
خط لولهٔ انتشار (نصب پیش‌نمایش ← فعال‌سازی tenant-scoped ← رندر).

## نتیجه

| بررسی | پایه (TT5) | فرزند امضاشده |
|---|---|---|
| پابرگ خود artefact (`.site-footer` + «قدرت‌گرفته از IGBZ») | ✗ (پابرگ والد) | ✅ |
| کارت‌های محصول ویترین | ۱۶ | ۱۶ |
| سرریز افقی | ۰ پیکسل | ۰ پیکسل |
| خطای JS | ۰ | ۰ |
| تصویر خراب | ۱ (gravatar — بیرونی/مسدود) | ۱ |

مقایسهٔ ساختاری روی رندرهای واقعی (سرویس `snapshot_diff` روی HTML واقعی هر دو
حالت): **۱۹ امضای بلوک مشترک**؛ تنها حذف‌شده = `h2` عنوانِ والد در پابرگ که فرزند
با پاراگراف خودش جایگزین کرده — یعنی خط لولهٔ انتشار همان چیزی را می‌کارد که
قرارداد گفته، نه بیشتر.

## محدودیت صادقانه

- بینایی مدل در این جلسه خاموش بود؛ شواهد = DOM خوانده‌شده با کرومیوم + دو
  اسکرین‌شات تمام‌صفحه (`storefront-base.png`، `storefront-child.png`).
- در این اجرا ست‌کردن `FONTCONFIG_PATH` (که fonts.conf آن به مسیرهای ناموجود اشاره
  دارد) رندرر کرومیوم را می‌کراند؛ حذف شد و اسکرین‌شات‌ها با فونت جایگزین سیستم
  گرفته شدند (چیدمان/رنگ دقیق، گلیف‌ها ممکن است fallback باشند).

## تأیید زندهٔ همراه

دود ۱۰گامی `/?igbz_release_smoke=1` همه‌سبز (کاوشگر موقت، حذف‌شده): ثبتِ قالب
با **امضای خودکار** (SHA-256 + HMAC در metadata) ← راستی‌آزمایی ← نصب پیش‌نمایش ←
**فعال‌سازی tenant-scoped** روی مستأجر واقعی (سطر tenants.theme عوض شد، ردیف live) ←
**rollback واقعی** (بازگشت به twentytwentyfive همان مستأجر) ← دستکاریِ بایتِ
بستهٔ ذخیره‌شده روی دیسک ← راستی‌آزمایی `signature_mismatch` و **رد در هر دو مرز**
(نصب پیش‌نمایش و فعال‌سازی). جزئیات در PROJECT-STATE §۱۱.۱۷.
