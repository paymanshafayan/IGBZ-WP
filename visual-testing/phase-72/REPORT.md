# گزارش تست ویژوال فاز ۷۲ — ستون «Last backup» و سبز ماندن پنل

تاریخ: ۱۴۰۶/۰۶/۱۰ · صفحهٔ هدف همان صفحهٔ وضعیت است (`admin.php?page=igbz`)؛
ابزار و روش عین فاز ۷۱ (`../phase-71/visual-check-slo-71.cjs`، کرومیوم
واقعی، axe-core، PNG تمام‌صفحه). تصاویر این فاز: `status-backup-desktop.png`
و `status-backup-mobile.png` (جدول سنجه‌ها اکنون ۷ ستونی است)؛ خروجی خام:
`visual-backup-report.json`.

## شواهد زندهٔ زنجیرهٔ پشتیبان (نه فقط UI)

1. ضربان روزانه با «Run now» اجرا شد → کار `cron.backup` (با کلید slot
   روزانه) enqueue شد؛ ضربان پنج‌دقیقه‌ای صف را راند؛ هر دو ۲۰۰.
2. صفحهٔ وضعیت پس از آن: «Jobs done (24h) = 28»، صف صفر، و ستون
   «Last backup = 0 min ago» — یعنی باندل واقعاً روی دیسک نوشته شد و مهر
   `igbz_last_backup` خورده؛ پنل SLO همه سبز.
3. a11y کل صفحه پس از افزودن ستون: **صفر نقض** (همان نتیجهٔ اصلاح‌شدهٔ ۷۱).
4. کنسول: خطای گذرای `reading 'serialize'` فقط در نخستین ناوبری پس از
   لاگین دیده می‌شود (روی pado هم هست، با ناوبری دوم می‌رود — بالادستی،
   پیش از ۷۲ هم ثبت شده). overflow موبایل همان سرریز جعبه‌بندی wp-admin
   است؛ عنصر برگی بیرون نمی‌زند (کاوش فاز ۷۱).
