# گزارش تست ویژوال — فاز ۵۷ (صف مجوز اتمیک)

تاریخ: ۱۴۰۶/۰۶/۰۹ (۲۹ اوت ۲۰۲۶) · ابزار: Chromium واقعی (Playwright 1.62.1 + @sparticuz/chromium 149)

## سطح بازبینی‌شده

فاز ۵۷ سرویس/اسکیما است؛ صفحهٔ مالکِ دامنه = تب «درخواست‌های مجوز» مرکز پادو
(`wp-admin/admin.php?page=igbz-pado&tab=approvals`) که سرویس ارتقایافته را بار می‌کند.

## نتیجه

| بررسی | نتیجه |
|---|---|
| رندر تب مجوزها + جدول + فرم‌های تصمیم | ✅ |
| سرریز افقی | ۰ پیکسل ✅ |
| خطای JS | ۰ ✅ |
| تصویر خراب | ۱ (gravatar — مورد شناخته‌شده) |

تأیید زندهٔ تکمیلی: دود شش‌گامی `/?igbz_queue_smoke=1` همه‌سبز — از جمله مهاجرت واقعی
v44 روی جدول مستقر (ستون‌های صف جدید همگی حاضر)، idempotency، گیت capability،
مالکیت claim با ردِ رقیب، مسیر ممیزی کامل (submitted→decided→claimed→executed)،
راستی‌آزمایی integrity و جاروب انقضا.
