تاریخ: ۱۴۰۵/۰۶/۰۹

## دامنهٔ بررسی

محیط محلی WordPress Playground با WordPress 7.0.4، WooCommerce 11.0.1، PHP 8.2 و افزونهٔ IGBZ اجرا شد. Chromium واقعی از بستهٔ npm `@sparticuz/chromium` استخراج و با Playwright اجرا شد؛ از `npx playwright install` استفاده نشد.

۲۵ مسیر قابل‌دسترسی از منوی IGBZ با viewport دسکتاپ ۱۴۴۰×۱۰۰۰ باز شدند و برای هرکدام اسکرین‌شات تمام‌صفحه در همین پوشه ذخیره شد:

## اصلاحات انجام‌شده

- پوشهٔ قدیمی `visual-testing` کاملاً پاک شد و تصاویر قبلی در آن نگه‌داری نشدند.
- CSS مشترک پنل برای RTL، فاصله‌گذاری، کارت‌ها، جدول‌ها، فرم‌ها، پیام‌ها، دکمه‌ها و نمایش موبایل اضافه شد.
- بارگذاری CSS فقط روی صفحات IGBZ انجام می‌شود.
- رشته‌های عنوان و منوی اصلی و بخشی از رشته‌های Status، Settings و Tenants به فارسی اضافه شد و فایل MO دوباره ساخته شد.
- صفحهٔ Store dashboard از `wp_die` خام به صفحهٔ استاندارد با عنوان، پیام راهنما و کارت وضعیت تبدیل شد؛ حالت «فروشگاهی به حساب اختصاص داده نشده» اکنون صفحهٔ سفید و بدون قالب ایجاد نمی‌کند.
- صفحات با مرورگر واقعی دوباره باز و اسکرین‌شات‌ها بعد از اصلاحات بازتولید شدند.

## وضعیت صداقت‌سنجی

این کار در وضعیت فعلی **کامل اعلام نمی‌شود**. علت: همهٔ متن‌های توضیحی و برچسب‌های داخلی تمام صفحات هنوز ترجمهٔ فارسی نشده‌اند و آزمون کلیک/ارسال مخرب یا تغییردهنده روی همهٔ دکمه‌ها انجام نشده است؛ اجرای کورکورانهٔ آن‌ها می‌توانست دادهٔ محیط تست را تغییر دهد. بنابراین این سند گزارش پیشرفت واقعی و موارد باقی‌مانده است، نه ادعای تکمیل کامل.

## موارد باقی‌مانده

- تکمیل ترجمهٔ فارسی تمام رشته‌های هر ۲۵ صفحه، شامل توضیحات، وضعیت‌ها، گزینه‌ها و پیام‌های فرم.
- بررسی چشمی جداگانهٔ هر صفحه پس از تکمیل ترجمهٔ همان صفحه.
- تست ایمن دکمه‌ها و فرم‌ها با دادهٔ آزمایشی کنترل‌شده و بررسی پیام موفقیت/خطا.
- رفع هشدار stale بودن `PHASE-01-INVENTORY.json` پس از تصمیم دربارهٔ به‌روزرسانی موجودی پروژه.
