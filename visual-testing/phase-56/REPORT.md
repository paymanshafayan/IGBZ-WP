# گزارش تست ویژوال — فاز ۵۶ (apter مستقل DeepInfra)

تاریخ: ۱۴۰۶/۰۶/۰۹ (۲۹ اوت ۲۰۲۶) · ابزار: Chromium واقعی (Playwright 1.62.1 + @sparticuz/chromium 149)

## سطح بازبینی‌شده

فاز ۵۶ UI ندارد (قرارداد + adapter + toolbox + گیت‌ها). صفحهٔ مالکِ دامنه = مرکز پادو
(`wp-admin/admin.php?page=igbz-pado`) که ماژولش سیم‌کشی جدید را بار می‌کند.

## نتیجه

| بررسی | نتیجه |
|---|---|
| رندر مرکز پادو (عنوان: Pado — AI Center) | ✅ |
| تب‌ها (طراحی قالب/درخواست‌های مجوز/تاریخچه/تنظیمات) + جدول + فرم | ✅ |
| سرریز افقی | ۰ پیکسل ✅ |
| خطای JS | ۰ ✅ |
| تصویر خراب | ۱ (gravatar — شبکهٔ سندباکس، مورد شناخته‌شده) |

تأیید زندهٔ تکمیلی: دود `/?igbz_ai_smoke=1` هفت‌گامی همه‌سبز — adapter در کانتینر
(`pado.ai.deepinfra`)، endpoint پیش‌فرض، allowlist ابزار، امتناع سه‌گانه (گیت خاموش /
کلید غایب / مدل بیرون لیست)، تفکیک داده/دستور، و رسیدن صادقانه تا سیم با
`provider_request_failed` (شبکهٔ سندباکس بسته است — هیچ کلید واقعی مصرف نشد).

⚠️ بینایی تصویر این جلسه خاموش بود؛ بازبینی DOM/CSS طبق §۸ هندآف؛
