# فاز ۶۸ — تست ویژوال بستهٔ فارسی و checkout

تاریخ: ۱۴۰۶/۰۶/۱۰ · ابزار: کرومیوم v149 واقعی + Playwright · اسکریپت: `visual-testing/phase-68/visual-check-release-68.cjs`

فاز ۶۸ لایهٔ بومی‌سازی است؛ شاهد ویژوال = سالم‌ماندن سطوح با لایهٔ جدید FaStorefront فعال (ارقام فارسی ویترین، قیمت‌های تومان IRT):

| صفحه | شواهد | نتیجه |
|---|---|---|
| ویترین `/` | ۱۶ کارت، قیمت‌ها با «تومان»، ارقام فارسی در متن، overflowX=۰، **صفر خطای کنسول** | ✅ |
| مرکز پادو | چهار زبانه، overflowX=۰، صفر خطای JS | ✅ |
| سلامت وردپرس | بدون خطای مهلک | ✅ |

نکتهٔ کلیدی ویژوال: تبدیل ارقام فقط در گره‌های متنی انجام می‌شود — بررسی پیکسلی/گیت‌واگ: `width="800"` و `/uploads/2026/…` و `data-product_id` دست‌نخورده، ارقام داخل `<script>/<style>` تبدیل نشدند (خطای SyntaxError قبلی بازنگشت؛ صفر خطای کنسول اثبات می‌کند). صفرِ خطای کنسول زیر بار تبدیل ارقام، مهم‌ترین شاهد این فاز است.
شواهد اختصاصی بی‌مرورگر (دود زندهٔ ۱۰/۱۰ + مهمان): بارگذاری `igbz-suite-fa_IR.mo` با موتور خود وردپرس و پاسخ فارسی رشته‌ها، ثبت IRT/تومان، پیش‌فرض `IR` تسویه برای مهمان از Store API، جلالی/تومان درست.
