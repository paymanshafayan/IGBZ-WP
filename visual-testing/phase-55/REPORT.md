# گزارش تست ویژوال — فاز ۵۵ (قرعه‌کشی، insights، ورودی رقبا)

تاریخ: ۱۴۰۶/۰۶/۰۹ (۲۹ اوت ۲۰۲۶) · ابزار: Chromium واقعی (Playwright 1.62.1 + باینری @sparticuz/chromium 149)

## سطح بازبینی‌شده

فاز ۵۵ هیچ UI جدیدی نساخت (سرویس‌ها + ۱۸ مسیر REST + اسکیما). بنابراین:
۱) پوستهٔ ادمین (پیشخوان) برای اطمینان از سالم‌ماندن رندر؛
۲) خروجی زندهٔ REST جدید از دل مرورگر واقعی (fetch با کوکی + nonce) — `GET /wp-json/igbz/v1/ig/giveaways`.

## نتیجه

| بررسی | نتیجه |
|---|---|
| پیشخوان رندر می‌شود (عنوان: Dashboard ‹ شاپ بیوتی) | ✅ |
| سرریز افقی | ۰ پیکسل ✅ |
| خطای JS (pageerror) | ۰ ✅ |
| تصویر خراب | ۲ (gravatar — بسته بودن شبکهٔ سندباکس، مورد شناخته‌شده) |
| REST از مرورگر: وضعیت | ۲۰۰ ✅ |
| REST از مرورگر: بدنه | قرعه‌کشی `growth smoke` با وضعیت `drawn`، برنده `smoke_c`، تعهد seed و هش استخر آشکار ✅ |

تأییدهای زندهٔ تکمیلی (curl با کوکی+nonce): `POST …/giveaways/1/audit/verify` → ۲۰۰ و بازمشتق همان برنده؛
`GET …/insights` و `GET …/competitors` → ۲۰۰ با ردیف‌های دود. دود زندهٔ ۷گامی `/?igbz_growth_smoke=1`
(شامل بازسازی جدول `ig_publish_events` با مهاجرت v43 روی سایت شبیه‌سازی‌شدهٔ مستقر) همه‌سبز.
