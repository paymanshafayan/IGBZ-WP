# اسکیل‌های پادو

این پوشه محل اسکیل‌های پادو است. تصمیم ۱۴۰۶/۰۵/۳۱:

- **اسکیل‌های خودمان** (با پیشوند `igbz-*`، مثل `igbz-store-theme/`)، که توسط تیم پروژه
  نگاشته می‌شوند، **در همین پوشه قرار می‌گیرند و کامیت می‌شوند** تا تاریخچهٔ
  تغییراتشان در گیت ثبت باشد.
- **اسکیل‌های شخص ثالث** (دانلودشده از مخازن بیرونی، مثل `ui-ux-pro-max-skill`) در
  زیرپوشهٔ `_thirdparty/` قرار می‌گیرند و **git-ignored** هستند (قابل بازیابی از
  مخزن/URL مرجع در هر زمان).

هر اسکیل از فرمت استاندارد `SKILL.md` + پوشهٔ `references/` پیروی می‌کند.
هستهٔ ویرا (`vira/`) این پوشه را (همراه با `~/.vira/skills/` در استقرار سراسری)
به‌عنوان یک رجیستری محلی می‌خواند.
